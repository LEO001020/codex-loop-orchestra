### R8 规格核验分类

#### 已支持 (Verified & Compatible)
- Windows Proactor 架构 (符合 Python 3.14+)。
- R8 §16 的 transcript 增量捕获机制。
- 插件 MCP 声明方式 (plugin.json + .mcp.json)。
- Git merge-tree fan-in 策略。
- ipykernel 7.3.x + MCP 2.1.1 的版本策略。

#### 部分支持 / 需调整 (Partial / Needs Adjustment)
- SessionStart 注入契约：R8 原文要求裸文本 stdout 输出，实际需要符合 JSON schema ({\ additionalContext\: \...\)。
- Clone seed：原文建议裸 sha 刷新，应修正为按 Git refspec 刷新以保证绝对安全。
- 目标 checkout：原文未指认，实际需在 gen8（有大量未提交）与 orchestra（更干净）间消歧。

#### 错误 / 不可实行 (Erroneous / Invalid)
- /goal 续接模型：本机无此命令，全量检索命中 0。
- injectAgentsMd 字段：字段不存在，会被 CLI 忽略。
- R8 引用的 ZCode \v3.7.1\ 里程碑：本机版本为 3.11.2，无确证历史。

#### 不可核验 / 截断范围 (Untestable / Truncated)
- 规格原文在 §26 (Windows K runtime) 之后截断，MCP 生命周期后续部分、具体 oracle 实现细节、构建测试流程等均无法核验。
