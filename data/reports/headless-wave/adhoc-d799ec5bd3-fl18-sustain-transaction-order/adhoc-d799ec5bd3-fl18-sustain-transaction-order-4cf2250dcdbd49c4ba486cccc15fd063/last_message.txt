#### 部署事务顺序（关键路径）

```

2. BACKUP       VACUUM INTO backup sqlite + 完整性校验  → BACKUP_READY=1
3. INSTALL      TCB bundle 安装到 /opt/p5/authority-v3  → INSTALL_STARTED=1
```

**顺序合规性：** ✅ 正确。`PRE-RELOAD` 验证严格发生在 `daemon-reload` 之前，`LIVE` 验证严格发生在 `start` 之后，`researchctl verify/rebuild-check` 发生在 `LIVE` 之后，`TRANSACTION_COMPLETE=1` 仅在所有验证通过后设置。

`trap rollback_deploy_transaction EXIT` 覆盖从 `STOPPED=1` 到 `TRANSACTION_COMPLETE=1` 整个窗口。回滚顺序：
1. stop → 恢复 WAL/SHM/sqlite → 恢复 researchctl/unit/dropin → daemon-reload → start old v2
