## 结论

**已证实发现：**

| 检查项 | 结果 |
|--------|------|
| 当前用户 | `desktop-3l9c649\codexsandboxoffline`（受限沙箱账户） |
| `C:\Users\hzq00\Downloads\platform-tools-latest-windows\platform-tools\adb.exe` | **文件存在**（8,273,560 字节） |
| platform-tools 版本 | **37.0.1**（`source.properties` 中 `Pkg.Revision=37.0.1`） |
| 架构 | Windows x86_64（来自 `NOTICE.txt` 中 `sdk-repo-windows-x86-platform-tools.zip`） |
| `C:\Users\hzq00\Downloads\platform-tools-latest-windows\platform-tools` 在 PATH 中 | **不存在** |
| `where.exe adb` / `Get-Command adb` / `cmd /c where adb` | **全部未找到** |

**根本问题：**

1. **PATH 缺失**：`C:\Users\hzq00\Downloads\platform-tools-latest-windows\platform-tools` 未加入用户级或系统级 PATH，因此任何目录下都无法直接调用 `adb`。
2. **沙箱权限限制**：当前以 `codexsandboxoffline` 身份运行，且 `HOME` 环境变量未定义。adb 启动时会尝试在 `\.android` 创建目录（因 `HOME` 为空而解析为根路径），导致权限拒绝崩溃。这属于运行时环境问题，不影响 PATH 配置本身。

**最小修复命令（将 platform-tools 加入用户 PATH）：**

```powershell
[Environment]::SetEnvironmentVariable(
    "Path",
    [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\Users\hzq00\Downloads\platform-tools-latest-windows\platform-tools",
    "User"
)
```

执行后需**重启终端**或运行 `refreshenv`（Chocolatey）使 PATH 生效。此后 `adb` 即可全局调用。
