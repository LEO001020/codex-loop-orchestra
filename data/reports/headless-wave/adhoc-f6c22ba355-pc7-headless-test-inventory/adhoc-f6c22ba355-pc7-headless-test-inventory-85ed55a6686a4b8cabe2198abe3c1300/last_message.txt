## 1. pytest 盘点结论：本项目不使用 pytest

- 全工作区（E:\VPS 根、`.work`、`.tools`、`tmp_probe`、`home-gpu`）**没有 pytest.ini / conftest.py / pyproject.toml / setup.cfg / tox.ini / requirements.txt**，也没有任何 `pytest` 调用。
- PC6 与 Track3 测试是**自运行脚本**：`if __name__ == "__main__": raise SystemExit(main())`，`main()` 遍历 `globals()` 中 `test_*` 函数，逐个 try/except，输出 `PASS/FAIL` 行 + 末尾 JSON 摘要（`{"run","pass","fail","failures"}`），以退出码 0/1 判定。
- Hub 基础设施测试用标准库 `unittest`（`setUp/tearDown` + `tempfile.TemporaryDirectory`，`unittest.main()` 收尾），同样不是 pytest。
- "fixtures" 概念上不存在 pytest fixture；等价物是测试文件内的辅助函数（如 `fixture_revision()`、`check()`、`expect_raises()`）和 unittest 的 `setUp`。

## 6. Synthetic golden test 分组设计（不触碰 real labels）

沿用现有 24 个可合成化测试 + legacy `null_oracle` 的 `SYNxxUSDT` 惯例，按被测函数切分为 8 组，每组可独立成 `test_pc6_synthetic_golden_<group>.py`（保持无 pytest 的自运行脚本约定）：

- **G1 摘要与 URL 原语**：`sha_bytes/canonical_bytes/canonicalize_http_url/parse_checksum`。已有：checksum 匹配、文件名 fail-close、unicode/percent 编码。补：idna 国际化域名、非法 checksum 行（3 段/非 hex/错文件名）、`canonical_bytes` 排序键确定性（中文键）。
- **G2 不可变存储与 revision 谱系**：`atomic_write_once/atomic_update_pointer/parent_revision_id/prior_latest`。已有：write-once 同字节幂等、异字节冲突、parent 逻辑。补：`atomic_update_pointer` 原子替换、临时目录中伪造多个 revisions 验证 `prior_latest` 按 retrieval 时间取新、目录缺失自动 mkdir。
- **G3 时间戳归一化与工程窗口边界**：`normalize_timestamp/month_end_us/month_range/START_US`。已有：spot 2024/2025 单位切换、futures 单位、3 个月 range。补：闰月/跨年 `month_end_us`、`normalize_timestamp` 越界值 fail-close（秒级/微秒级拒收）、窗口边界条（`open_time_us == START_US` 边界条 `in_engineering_window` 真/假各一）。
- **G4 身份映射 fail-close 矩阵**：`direct_identity_map`（全部用 SYNxxUSDT 合成 metadata dict）。已有：VERIFIED、UNRESOLVED_UNIT_MAPPING、NO_SPOT_PAIR。补：absent futures、非 PERPETUAL、非 USDT 计价、non-COIN underlying、`pair != symbol`、spot 有 metadata 但无 archive 六分支逐一断言 `status/exclusion_reasons`，并断言 `mapping_confidence=="FAIL_CLOSED"` 仅出现在非 VERIFIED。
- **G5 条闭合与 8h 固定时钟**：`prior_completed_utc_day_quote_volume/fixed_common_clock_8h_us`。已有：前一日成交量求和、半开区间成员、非整点 anchor fail-close。补：跨 UTC 日边界事件排除、end 时刻事件不进窗、空事件窗计数 0。
- **G6 funding 结算语义**：`actual_settlement_to_settlement_us`。已有：4h→8h 可变区间、非单调 fail-close。补：`raw_duration` 超 `SNAP_TOLERANCE_US` fail-close、声明间隔与实距一致性、右截断（末事件不虚构 end）。
- **G7 normalize_revision golden fixtures**（核心分组，全 temp-dir + 手算期望）：kline 归一化（`market_event_time_us` 取 close_time、observable=+1us、ingested/published 时间链）、spot pre-2025 条、funding 行、重复键 fail-close、错误 header/宽度 fail-close。补：`raw_open_time` 原样保留、`row_count`/`first/last_market_event_time_us`、normalization record 自哈希一致、parquet 写后 `sha_file` 与 `normalized_output_sha256` 相等。
- **G8 合成 artifact 管线一致性**：`artifact/canonical_bytes` 的 canonical_id 注入与哈希自洽、`load_normalizations/load_normalization_conflicts` 空目录与排序行为（用合成 JSON 造目录）。**不进入** `build_artifacts/enumerate_plan/download_*`（需真实 exchangeInfo/网络/S3，天然排除）。

分组护栏（写进每组定义）：不读 `P5_PC6_BINANCE_ROOT`/`P5_PC6_BINANCE_ARTIFACTS` 环境变量；不 import 任何 `P5_P3_*`/`P5_PC6_*` artifact；symbol 一律 `SYNxxUSDT`、月份用 2023-07~2026-07 之外的合成月；全部 temp-dir 生命周期；零网络；不执行 T1/H0/H2/D4 与任何统计/科学运行；断言失败必须走显式 fail-close（RuntimeError/AssertionError）。
