   ```powershell

   ```
3. **验证 adb 可用**：
   ```powershell
   adb version
   ```
4. **从同一 PowerShell 会话启动 UAD**：
   ```powershell
   & "C:\Users\hzq00\Downloads\uad-ng-windows.exe"
   ```

> **注意**：不要通过双击或从旧 cmd/PowerShell 会话启动 UAD，因为那些会话可能继承的是旧 PATH（不含 adb 路径）。始终从已显式追加 PATH 的同一新会话中启动。
