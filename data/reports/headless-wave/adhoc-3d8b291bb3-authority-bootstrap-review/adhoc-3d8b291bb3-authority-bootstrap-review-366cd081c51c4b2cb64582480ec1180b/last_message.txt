## 权限兼容引导复核 — 对抗性审查报告

### 审查范围与引擎约束确认

冻结引擎要求在 `derive_outcomes` 之前必须满足以下全部前置条件，缺一不可：

1. **提案绑定行（proposal binding rows）** — 已持久化，含 arm receipt
2. **精确科学观察（exact scientific observations）** — outcome-free，PC6 observe 阶段完成
3. **PRECONDITIONS_PASS 证据** — 明确记录
4. **最新状态已应用（latest state APPLIED）** — FSM 状态机已推进至正确节点
5. **持久化 label_access_ledger** — derive_outcomes 调用前写入完毕

---

### 原始仪式评估（C / D / root / A / B 所有者仪式）

> **结论：WAIVED_NOT_PASSED**

原始所有者仪式（C/D/root/A/B owner ceremony）**已豁免，绝不得报告为 PASS**。任何将豁免重新标记为通过的写法均构成不可接受的宽泛绕过。豁免必须在 label_access_ledger 中以独立行显式记录，字段示例：

```
ceremony_status: WAIVED_NOT_PASSED
waiver_reason:   fast-path compatibility bootstrap
waiver_scope:    C/D/root/A/B owner ceremony only
waived_by:       <授权方标识>
waived_at:       <时间戳>
```

---

### 最窄快速路径兼容引导方案

该方案仅针对 database/FSM 依赖的引导需求，不扩大权限边界。

**步骤 1 — 最小 schema 迁移（仅数据库依赖）**
仅执行快速路径所需的表/列创建或迁移，不修改现有权限列或角色映射表。范围：新增 bootstrap_state 跟踪行，不触碰 access_control 表。

**步骤 2 — FSM 初始状态注入**
将 FSM 推进至 `BOOTSTRAP_READY` 节点（而非跳过至 `ACTIVE`），确保 latest state = APPLIED 的证据可查。禁止直接写入终态节点以绕过中间状态转换检查。

**步骤 3 — 提案绑定行写入**
在任何 observe 调用之前，持久化 proposal binding rows，含：proposal_id、arm_id、arm_receipt（不可变哈希）。arm receipt 必须在此阶段绑定，不得在 derive_outcomes 后补写。

**步骤 4 — PC6 outcome-free observe**
执行 PC6 observe，严格保持 outcome-free。禁止在此阶段写入任何结果相关字段。观察结果仅写入 observation_log，不触发状态转换。

**步骤 5 — PRECONDITIONS_PASS 证据记录**
在 derive_outcomes 调用前，生成并持久化 PRECONDITIONS_PASS 断言记录，内容包含：所有前置步骤的完成时间戳、校验哈希、FSM 当前节点快照。

**步骤 6 — label_access_ledger 写入**
持久化 label_access_ledger，含 WAIVED_NOT_PASSED 条目。此步骤必须在 derive_outcomes 之前完成，顺序不可调换。

**步骤 7 — derive_outcomes 调用**
全部前置条件满足后方可调用。

---

### 不可接受的宽泛绕过清单

以下任何一项均构成违规，必须拒绝：

| 绕过方式 | 违规原因 |
|---|---|
| 将 WAIVED 重标记为 PASS | 掩盖豁免事实，破坏审计链 |
| 在 derive_outcomes 后补写 arm receipt | 违反提案绑定先于结果的时序要求 |
| 跳过 PC6 observe 直接进入 derive_outcomes | 缺失科学观察，结果不可信 |
| 在 observe 阶段写入结果字段 | 破坏 outcome-free 约束 |
| 直接将 FSM 写入终态节点 | 绕过中间状态检查，latest state APPLIED 证据失效 |
| 省略 PRECONDITIONS_PASS 记录 | derive_outcomes 前置证据链断裂 |
| 省略或延迟 label_access_ledger 写入 | 违反持久化时序要求 |
| 以"兼容引导"为由扩大 schema 权限列修改范围 | 超出最窄快速路径边界 |
| 合并仪式豁免与条件通过为单一状态字段 | 模糊豁免与通过的语义区分 |

---

### 科学检查保全声明

本方案**不削减任何科学检查**。所有 observe 约束、outcome-free 要求、FSM 转换校验、proposal binding 完整性检查均保持不变。快速路径仅绕过所有者仪式，仪式豁免以 WAIVED_NOT_PASSED 显式记录，不影响其他检查的执行与证据收集。

---

**审查结论：** 上述最窄方案在满足 database/FSM 引导依赖的同时，完整保留冻结引擎的科学约束与时序要求，并以不可混淆的方式记录仪式豁免状态。任何偏离上述方案、扩大绕过范围或模糊豁免语义的实现均应被拒绝。
