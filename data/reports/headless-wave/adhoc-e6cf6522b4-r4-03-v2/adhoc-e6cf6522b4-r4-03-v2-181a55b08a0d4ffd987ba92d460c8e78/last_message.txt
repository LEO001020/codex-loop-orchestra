| Field | How enforced |
|---|---|
| `conclusion` | `not conclusion.strip()` → `EMPTY_FIELD:conclusion` |
| `packet_id`, `control_packet_id` | `not value.strip()` → `EMPTY_FIELD:<name>` |
| `needs_decision.question` | `minLength: 1` in JSON schema; `BAD_NEEDS_DECISION` in code |
