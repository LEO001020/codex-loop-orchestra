# Windows cloudflared 安装文档

## 1. 快速安装（推荐 - 非交互模式）

```powershell
winget install --id Cloudflare.cloudflared --disable-interactivity --accept-package-agreements --accept-source-agreements
```

## 2. 用户级无管理员权限回退安装

```powershell
# 1. 注册 winget 源（如果未注册）
winget source add -n winget-microsoft -r https://cdn.winget.microsoft.com/cache

# 2. 安装到用户目录（不要求管理员权限）
winget install --id Cloudflare.cloudflared --location "C:\Users\hzq00\AppData\Local\cloudflared" --disable-interactivity --accept-package-agreements --accept-source-agreements

# 3. 添加到 PATH（仅当前用户）
$env:Path += ";$env:USERPROFILE\AppData\Local\cloudflared"
[Environment]::SetEnvironmentVariable("Path", $env:Path, "User")
```

## 3. 手动安装（无 winget）

```powershell
# 下载最新 Windows amd64 版本
$latest = Invoke-WebRequest -Uri "https://github.com/cloudflare/cloudflared/releases/latest" -UseBasicParsing
$version = $latest.Links | Where-Object {$_.href -match "cloudflared-windows-amd64.exe"} | Select-Object -ExpandProperty href -First 1
$downloadUrl = "https://github.com" + $version

$downloadPath = "C:\Users\hzq00\Downloads\cloudflared.exe"
Invoke-WebRequest -Uri $downloadUrl -OutFile $downloadPath

# 移动到系统 PATH（用户级）
$targetDir = "C:\Users\hzq00\AppData\Local\cloudflared"
New-Item -Path $targetDir -ItemType Directory -Force | Out-Null
Copy-Item $downloadPath $targetDir -Force
$env:Path += ";$targetDir"
[Environment]::SetEnvironmentVariable("Path", $env:Path, "User")
```

## 4. 版本验证

```powershell
cloudflared --version
```

## 5. 常见问题

- **安装失败（权限错误）**：使用用户级安装或以管理员身份运行 `winget source reset` 后重试。
- **cloudflared 不可用**：重启 PowerShell 或注销当前会话。
- **Quick Tunnel 无法使用**：确保安装了 `cloudflared` 并在 PATH 中可用。
