## 本地监听端口图

```
┌─────────────────────────────────────────────────────────┐
│                    本地监听端口总览                        │
└─────────────────────────────────────────────────────────┘

  ┌────────────────────────────────────────────────────┐
  │  Home GPU Worker（本机 / WSL 内）                   │
  │                                                    │
  │  :8765  ──►  WebSocket/HTTP Observer               │
  │              · 接收 VPS 下发的推理任务              │
  │              · 上报 GPU 状态（显存、温度、利用率）   │
  │              · 心跳 keep-alive                     │
  │                                                    │
  │  :11434 ──►  Ollama REST API (本地 LLM 推理)        │
  │              · /api/generate  /api/chat            │
  │              · 仅 127.0.0.1 绑定，不对外暴露        │
  └────────────────────────────────────────────────────┘
            │
            │  SSH 反向隧道 / frp / ngrok
            │  (Home → VPS 的出站连接)
            ▼
  ┌────────────────────────────────────────────────────┐
  │  VPS 公网侧                                        │
  │                                                    │
  │  :80 / :443  ──►  Nginx 反向代理                   │
  │  :8080       ──►  File Browser Web UI              │
  │                   · 文件浏览/上传/下载              │
  │                   · 通过 Nginx 代理后对外提供服务   │
  │  :8765       ──►  Observer 中继端点                │
  │                   · 接受 Home GPU 的 WS 连接        │
  │                   · 转发控制指令 / 收集状态数据      │
  └────────────────────────────────────────────────────┘
```

### 各端口职责说明

| 端口 | 所在侧 | 组件 | 职责 |
|------|--------|------|------|
| **8765** | Home 本地 & VPS 中继 | **Observer** | WebSocket 双向通道；Home 端监听任务派发，VPS 端监听 Home 的连接注册；同时承担心跳、状态上报、任务结果回传 |
| **8080** | VPS | **File Browser** | 提供基于 Web 的文件管理界面；本地转发时（SSH -L 8080:localhost:8080）可在本机浏览器直接访问 VPS 文件系统，无需开放公网 |
| **11434** | Home 本地 | **Ollama（GPU Worker）** | 仅本地绑定；接收由 Observer 解包后转发的推理请求，输出 token 流再经 Observer 回传给 VPS |

### 数据流简述

```
用户请求
  → VPS Nginx (:443)
    → Observer 中继 (:8765)  ←→  Home Observer (:8765)
                                      ↓
                               Ollama GPU Worker (:11434)
                                      ↓ (推理结果)
                               Home Observer (:8765)  →  VPS 中继  →  用户
```

File Browser 走独立路径，不经过 Observer：

```
用户 (SSH 本地转发 -L 8080)  →  localhost:8080  →  VPS:8080 File Browser
```

**注意**：以上为只读分析，基于脚本命名约定与项目结构推断，未启动任何新的监听进程。如需核对实际绑定情况，可在 Home 端执行 `ss -tlnp | grep -E '8765|8080|11434'` 查看。
