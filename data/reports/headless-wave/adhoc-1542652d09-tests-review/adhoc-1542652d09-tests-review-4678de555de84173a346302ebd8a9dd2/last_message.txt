## 漏测详单

**A. 已确认缺陷（审阅报告级别）全部漏测：**

1. M1：没有任何测试重算 `sha256(落盘字节)` 与文件名/内嵌 `sha256` 的一致性——`test_actual_artifact_hashes_and_readiness` 只覆盖 5 个 `artifact()` 产物（该路径本身正确），恰好漏掉报告指出的 4 处自引用文件与 `view_specification_hash`；manifest 中 `enumeration_plan_semantic_sha256` 与 `enumeration_plan_file_sha256` 的语义关系也无人断言。
2. M2/C7：无测试断言同内容重跑产出一致，或捕获"同 out_dir 二次跑 artifacts 必然 WRITE_ONCE_CONFLICT"；`revision_id` 墙钟前缀语义未测。
3. M3：无测试断言 locator 为相对内容寻址或跨 root 迁移稳定。
4. M4：无测试把 `temporal_schema_sha256` 常量与真实 schema 源文件哈希对账；现有 33 号测试是 `needed <= names` 超集检查，schema 变更（增删列）不触发失败。
5. M5：无测试校验 normalization 记录 `transform_code_sha256 == sha_file(当前代码)`、manifest `build_code_identity.file_sha256` 与全部 norm 记录一致、`git_commit` 与 `P5_BUILD_GIT_COMMIT` 一致；`P5_BUILD_GIT_COMMIT_REQUIRED` fail-close 未测。

**B. 管线 fail-closed 分支零覆盖：** download 的复用短路（幂等核心：同 checksum+blob 不产生新 revision）、CHECKSUM_MISMATCH、CONTENT_LENGTH_CONFLICT、ZIP_CRC_FAILURE、ZIP_MEMBER_SCHEMA、ZIP_INVALID、`DOWNLOAD_FAILURES` raise、`parse_checksum` 边界（大写 hex/多余 token/CRLF/空文件）、`http_date_to_iso`；normalize 的 KLINE_HEADER/KLINE_WIDTH/FUNDING_WIDTH/单位拒绝、NON_MONOTONIC、SNAP_TOLERANCE、RAW_REVISIONS_MISSING、非 DUPLICATE 失败归类、续跑跳过幂等；artifacts 的 NORMALIZATION_MISSING_WITHOUT_CONFLICT、BLOCKED 状态、readiness False 标志、`executable_cells` 三 dataset 哈希、lineage EXCLUDED 行字段、manifest hash 可由 lineage 重算（且 metadata 未计入 `raw_manifest_hash` 的误导性）；enumerate 的 S3 分页、gap 双因混类、空 `present` 集合幻影 cell（L405–406 `all()` 恒真）、INSUFFICIENT_STORAGE。

**C. 分支覆盖不足：** identity 未测 NOT_PERPETUAL、NOT_USDT_LINEAR_SCOPE、NON_CRYPTO_UNDERLYING、FUTURES_PAIR_NOT_SYMBOL、futures 元数据缺失、spot 元数据存在但不在 archive 集合（10 号只测了空列表半边）；listing ledger 未测 deliveryDate 远未来哨兵（>4e12）、SETTLING→CURRENT_METADATA_DELIVERY_DATE、episode_id RAW 分支、source_disagreement、archive_months_missing、spot_availability。

**D. 结构性风险——真实数据 pinning：** `test_actual_plan_and_download_conservation`/`test_actual_normalized_plus_conflict_conservation`/`test_actual_artifact_hashes_and_readiness` 钉死 35403、0 失败、恰 1 个冲突且 key 为 EDUUSDT-1h-2026-06、READY——Binance 补档/重发（EDU 修复）或新增月份即 FAIL。且 31 号用计数相加，可被"一缺失+一意外"相互补偿掩盖；应改为集合恒等断言（plan objects keys == normalized identities ∪ conflict keys）+ manifest cells == plan cells − 冲突 cell 的全集守恒。10 项测试依赖远端 `/data/k3` 数据与产物，本地默认路径不存在且无 skip 标记，本地 CI 不可运行。

**正面项（避免误伤）：** fixture 型 normalize 测试（25–29）质量较好——真实写出 parquet 并断言 event/observable 时间、窗口标志、合成重复键、schema fail-close，独立于真实数据验证了 EDU 缺陷类别；write-once、parent、量边界、view 成员语义、EDU cell-local、artifact 字节哈希链、禁止替代字段均有价值。
