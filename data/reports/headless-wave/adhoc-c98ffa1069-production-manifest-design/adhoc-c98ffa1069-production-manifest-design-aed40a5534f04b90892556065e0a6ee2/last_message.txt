## 汇总：跨组件全局哈希 DAG

```
叶子字节(文件/脚本/schema/JSON)
   → 组件文件清单 P5_PRODUCTION_APP_V2_FILE_MANIFEST_V1  (逐文件 sha256)
   → 外层 MANIFEST.json / SHA256SUMS                     (嵌套引用内层清单 hash)
   → V5 信封                                            (body_prefix.sha256 回指 body)
   → 签名/仪式顺序                                      (preimage 不含签名；O3 root after D)
   → runtime 消费                                        (event 链 → projection → verify/rebuild)
```

无环保证来自四处强制：清单不含自身 digest（C-3/U-3）；所有引用指向严格前驱（event 链、supersedes、body_prefix、after-D）；append-only/write-once 触发器和 checkpoint 禁止改写已哈希内容；版本号（schema_version/SCHEMA_VERSION/v5-prefix-1）作为语义防环锚点，任何变更必须换版本使 digest 变化而非原地改写。

补充说明：组件名 "D" 在 ceremony 机器清单里同时指 O2 机器 D，与 delegation 组件同名不同物，本盘点按 delegation 设计解读 D，ceremony 内部 "D" 按其 binding 字段原样保留。
