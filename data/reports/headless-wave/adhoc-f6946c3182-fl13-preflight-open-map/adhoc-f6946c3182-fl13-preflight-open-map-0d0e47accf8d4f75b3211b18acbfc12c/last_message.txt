## 一、脚本契约与输出格式

| 元素 | 规则 |
|------|------|
| 执行身份 | 必须 **root**；非 root → 全面降级为 `[INDETERMINATE]`，`OPEN += 1`（永远无法产生 false CLEAN） |

## 四、false CLEAN 风险汇总（INDETERMINATE 设计的覆盖边界）

| 风险项 | 触发场景 | 防护机制 |
|--------|---------|---------|
| 非 root 执行 | sudoers / authorized_keys / polkit 不可读 | preamble INDET → exit 3 |
| `id -nG` 失败 | 账号损坏 | F7-16(a): 空组集 → INDET |
| `getcap` 缺失 | 精简系统 | INDET |
| cloud guest agent 重注入 | reboot 后恢复 sudo | Phase 4 hard gate `P5_CLOUD_REGRANT_NEUTRALIZED=YES` |
| root-owned polkit 内容授权 | 权限扫描无法见 | Phase 10 内容 grep (F10-11) |
| 预植后门 key（非 agent key） | agent 在 root-equiv 期间操作 | Phase 13 `P5_EXPECTED_AUTHKEY_FPS` 白名单 |
| 有密码单命令 sudo (GTFOBins) | 旧版仅看 NOPASSWD | F10-13 覆盖 "may run the following" |
| docker 多 unit 联合 `-T` pipefail 吞错 | `systemctl cat a b` 一个缺失 exit≠0 | F10-14 分开 per-unit 调用 |
| 容器镜像 overlay 内的 cap 二进制 | `getcap -r /` 扫到容器 layer | V10-A 路径跳过 |
