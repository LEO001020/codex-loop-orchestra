#### 资源目录结构 (目录: `E:\Program Files\ZCode\resources`)

| 资源路径 | 用途/说明 |
| :--- | :--- |
| `resources/app.asar` | 应用主逻辑打包文件 |
| `resources/config/` | 应用配置文件 (如 `default.json`) |
| `resources/glm/packages/` | 核心插件与扩展功能模块 (包含 `android-emulator-plugin`, `browser-use-plugin`, `document-skills-plugin` 等) |
| `resources/tools/` | 辅助工具集 (包含 `ripgrep/`, `ugrep/` 等搜索工具，以及 `cua-helper/`) |
| `locales/` | 语言包资源 (`zh-CN.pak`, `en-US.pak`) |

#### 推断与未知
- **推断**: `resource/glm/packages` 是 ZCode 扩展能力的主要载体，每个插件目录内部结构包含了 `commands`, `hooks`, `scripts`, `skills`, `.mcp.json` 等文件，表明其采用了模块化的插件架构。
- **推断**: `resources/tools` 下的 `ripgrep` 和 `ugrep` 表明 ZCode 依赖这些高速搜索工具进行代码库探索或审计。
- **未知**: `app.asar` 为二进制打包文件，未深入解析其内部逻辑结构。
